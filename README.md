# Flask Git Practical - Aryan

## Project Overview

This project demonstrates Git and GitHub version control using a Flask application.

## Practical Tasks

* Repository setup and SSH authentication
* Branch creation and merging
* JSON updates and merge conflict resolution
* To-Do frontend and backend development
* Sequential commits, Git reset, and rebase

## Technologies

* Python
* Flask
* Git and GitHub
* MongoDB
* HTML and CSS
* JSON
